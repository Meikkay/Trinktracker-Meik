# Arbeitsprotokoll – Trinktracker

## Unsere Arbeitsschritte

| Arbeitsschritt | Das haben wir selbst gemacht | Das hätte ein Agent übernommen |
|---|---|---|
| 1. App planen | Thema und drei Funktionen ausgewählt | Anforderungen auswerten und einen Plan erstellen |
| 2. Projekt vorbereiten | Repository und Projektdateien in GitHub angelegt | Dateien automatisch anlegen und ausfüllen |
| 3. App erstellen | Code von ChatGPT kopiert, als index.html gespeichert und veröffentlicht | Code selbst einfügen, speichern und veröffentlichen |
| 4. App prüfen | Knöpfe getestet und den Fehler mit der Internetadresse behoben | Tests durchführen, Fehler erkennen und Korrekturen vornehmen |

## Antworten auf die Fragen

### 1. Welche Handgriffe haben wir wiederholt?

Wir mussten Dateien öffnen, Texte kopieren, Änderungen speichern und auf „Commit changes“ klicken. Außerdem mussten wir Seiten neu laden und den aktuellen Stand prüfen.

### 2. Wie oft haben wir vergessen, STATUS.md zu aktualisieren?

Wir haben STATUS.md mithilfe einer Erinnerung aktualisiert. Ohne diese Erinnerung hätten wir die Aktualisierung leicht vergessen können.

### 3. Wo waren wir froh, selbst entscheiden zu können?

Bei der Auswahl der App und bei der Entscheidung, das Projekt öffentlich zu machen. Vor der Veröffentlichung konnten wir prüfen, dass keine persönlichen Daten enthalten sind.

### 4. Was hätte ein Agent unbemerkt tun können?

Ein Agent hätte falsche Dateien verändern, das Projekt öffentlich machen oder fehlerhaften Code veröffentlichen können, ohne dass wir es sofort bemerken.

### 5. Hätte ein Agent besser funktioniert?

Ein Agent hätte viele Arbeitsschritte schneller erledigt. Riskanter wäre gewesen, dass er selbstständig Dateien verändert oder etwas veröffentlicht. Deshalb sollte ein Mensch wichtige Änderungen vor dem Speichern und Veröffentlichen prüfen.
