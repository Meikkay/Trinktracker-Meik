# Regeln für unsere App

- Die Oberfläche ist auf Deutsch.
- Die App besteht aus einer einzigen Datei namens index.html.
- Es werden keine zusätzlichen Bibliotheken verwendet.
- Die App muss auf dem Handy bedienbar sein.
- Die App bekommt höchstens drei Funktionen.
- Der Code soll kurze und verständliche Kommentare enthalten.
